# 보행약자 통행 보조 시스템 개발 프로젝트
- 기간 : 2024.10.21 ~ 2024.11.18
- 인원 : 5명
- 기술 : Python, numpy, Jupyter, corab, pytorch, YOLO, OpenCV, FFmpeg


## 프로젝트 개요
점자블록 훼손 및 음향 신호기 미설치 등 시각장애인을 포함한 보행약자의 안전을 위협하는 장애 요소가 보행로에 산재해 있습니다. 기존의 공공 보조 수단만으로는 개별 보행 약자의 실시간 돌발 상황을 대처하기 어렵다는 한계가 존재합니다.
본 프로젝트에서는 AI-Hub의 인도 보행 데이터셋과 웹 크롤링으로 수집한 커스텀 데이터를 활용하여 실시간 위험 객체를 감지하는 딥러닝 기반 시스템을 개발하였습니다.
YOLOv8 Nano 모델을 기반으로 도로 위 장애물을 신속하게 탐지하고 관심영역(ROI) 분석 및 음성 안내(TTS) 기술을 결합하여, 보행약자의 시야를 보완하고 안전한 이동의 자유를 보장하는 개인화된 스마트 보조 솔루션 구현을 목표로 합니다.


## 프로젝트 목표
- **실시간 경량 객체 탐지 모델 구축:** 동영상 데이터의 실시간 추론 속도와 사용자 피드백 속도를 고려하여 최적의 초경량 모델인 YOLOv8 Nano 기반 커스텀 데이터 학습 진행
- **컴퓨터 비전 기술 활용 신호등 상태 구분:** 신호등 형태를 인식한 바운딩 박스 내에서 HSV 색상 필터를 적용해 보행 신호(초록불)와 대기 신호(빨간불)를 실시간으로 정밀 식별
- **관심영역(ROI) 기반 위험도 차등 검출:** 사용자 시점 기준의 관심영역(ROI) 마스크를 설정하고, 장애물의 근접도 및 이동 순서에 따라 탐지 우선순위를 시각적으로 차별화
- **TTS 기반 실시간 정보 음성 전달 안내:** 탐지된 객체의 종류와 위치(방향, 거리) 정보를 즉각적으로 텍스트화한 후 TTS(Text-To-Speech) 기술을 적용하여 사전에 위험을 인지할 수 있는 음성 안내 피드백 구현


## 데이터 출처
- 상권 기반 데이터: 서울 열린데이터광장 '서울시 상권분석서비스' 공공 데이터셋 (점포, 직장인구, 유동인구, 상주인구, 소득소비, 추정매출, 집객시설 등)
- 임대료 데이터: 한국부동산원 상업용부동산 분기별 지역별 임대료 데이터


## 분석 결과
서울시 공공 데이터와 임대료 데이터를 결합하여 상권을 4개 유형으로 재분류하고, 창업 컨셉별 최적의 입지를 매칭했습니다.
- **그룹 1. 주거 밀집 상권 (애놀라홈즈)**
    - 데이터 특성: 아파트 단지 수 및 총 상주인구 수가 서울시 평균을 크게 상회.
    - 비즈니스 매칭: 고객 유대감과 재방문율이 높은 **'단골 고객 중심의 동네 편안한 카페'** 컨셉에 최적.
- **그룹2. 대학가 상권 (젠리단길)**
    - 데이터 특성: 연령대별 점주 중 2030 비율이 높고, 전체 유동인구 중 2030 비중이 약 40%를 차지하나 월평균 소득은 가장 낮음.
    - 비즈니스 매칭: 카공족 및 학기 중 정기적인 유동인구를 타겟으로 하는 **'안정적인 프랜차이즈 카페'** 창업에 최적.
- **그룹3. 오피스 타운 상권 (커핏팡잇츠)**
    - 데이터 특성: 총 직장인구 수 1위, 주중 유동인구 대비 매출액 효율이 가장 압도적인 비즈니스 밀집 지역.
    - 비즈니스 매칭: 테이크아웃 위주로 피크타임(출근·점심)이 명확하고 빠른 퇴근이 가능한 **'소형/저가 커피 전문점'** 컨셉에 최적.
- **그룹4. 상업 활성화 상권 (트·민·상)**
    - 데이터 특성: 전체 유동인구 1위, 야간(21~24시) 매출 비중 최상위, 신생 점포 진입과 교체가 활발한 다이나믹한 번화가.
    - 비즈니스 매칭: 트렌디한 MZ세대의 소비가 집중되는 **'독특한 인테리어 및 시그니처 디저트 중심의 개인 카페'** 컨셉에 최적.


## 인사이트 및 비즈니스 가치
- **데이터 기반 리스크 최소화:** "유동인구가 많으면 잘될 것"이라는 직관적 오류를 깨고, 창업자의 자본(임대료)과 컨셉에 맞는 데이터 기반의 맞춤형 입지 전략을 제안하여 폐업 리스크를 낮춥니다.
- **타겟 맞춤형 운영 전략 가이드:** 상권별 소비 주도 연령대와 피크타임(예: 오피스 타운의 주중 출근·점심시간, 번화가의 야간 시간)을 명확히 제시하여, 창업 후 메뉴 구성 및 인력 배치 전략의 실질적 근거를 제공합니다.
- **공공 데이터의 비즈니스적 고도화:** 파편화된 공공 데이터를 '창업자 컨셉 대입형' 프레임워크로 재조합함으로써, 향후 프랜차이즈 출점 전략이나 상권 컨설팅 솔루션으로 확장 가능한 비즈니스 모델을 증명했습니다.

## 한계 및 보완점
- 자치구 단위 임대료 데이터로 행정동, 상가 단위 세부 분석 어려움.
- 군집 간 특색이 더 드러날 수 있도록 면밀한 k값 조정을 요함.
- 제한적인 기간 데이터 활용, 추가적으로 시기별 데이터를 활용하여 매출 추이 등 추가 세밀 분석이 가능할 것으로 예상.
- 군집 간 특성이 뚜렷하도록 다양한 변수 수집과 군집 수 선택을 조정하여 더 많은 창업자의 요구 사항을 더욱 세밀하게 커스텀화 하는 방향으로 보완.


## 결론
- 분석 결과를 활용해 카페 컨셉과 잘 맞는 상권을 선정하고, 타겟 고객을 구체적으로 파악해 창업자의 영업 전략을 수립할 수 있을 것으로 예상.
- 이런 응용 분석 방안을 제시함으로써 창업자의 개인화된 특성을 대입한 분석 방안을 활용해 있음을 강조하며, 궁극적으로 창업자의 목표와 환경에 맞춘 최적의 입지 선정이 가능해짐.
- 이를 통해 창업자는 직관적인 데이터에 의존하는 것이 자신의 시장 상황을 고려한 맞춤형 전략을 수립할 수 있게 되며, 이는 성공 가능성을 높이고 리스크를 보다 효과적으로 관리할 수 있는 도구가 될 것.
